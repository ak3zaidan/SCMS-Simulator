This page is the release checklist for a 1.0 tag, included verbatim from the repository so
the site and the file cannot disagree. It lists what must be true, what is currently not
true, and what each gap would take.

It is deliberately the least flattering page on this site. A research tool's readers are
deciding whether to trust a number, and the fastest way to help them is to say which
numbers are not ready — so the checklist names the stub at the message layer, the 121-fold
performance gap and the validation suite that has never run, in those words.

The rows that a generator can produce are produced: the calibration count comes from the
[completeness gate](gate.html), the validation matrix from the
[campaign report](campaign.html), and the defect history from the
[register](defects.html). The rows that state a judgement — what a gap would take, and
whether it will close — are hand-written and dated for that reason.
