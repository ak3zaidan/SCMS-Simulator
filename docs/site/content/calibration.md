A parameter on this page has a value the engine uses and no source that supports it.
That is not a bug and it is not hidden: the card schema refuses an uncited default
unless it is declared as one *and* carries a plan for replacing it, so this page is the
complete list of what the project owes.

It exists because the alternative is worse. A simulator with no such page does not have
fewer guesses in it; it has the same guesses with nothing marking them, which is how a
number chosen to make a plot look sensible ends up in someone's published result three
years later.

**How to use it.** Before quoting a result, check whether any parameter it depends on
appears below. If one does, either calibrate it, or run the sweep the plan describes
and report the sensitivity, or say in the caption that the result is provisional in
that respect.
